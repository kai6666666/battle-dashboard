## 六、归属裁决（2026-10-04 追加 · 代码级）

> 本章是对第四节"4 件合并建议"的深化：把"谁合并谁打架"的粗结论，升级为
> **"每域定唯一 owner + 具体归属 + 代码级原因"**。
> 证据来源：两仓库实际源码（A=BasedonST v2.0.4；B=骰子系统 x9 拆解后）。

### 6.1 五条判断准则

| # | 准则 | 含义 | 典型适用 |
|---|---|---|---|
| ① | 单一计算源 | 同一规则只能有一个算法实现 | 检定/投骰 → 全走 B 的 AcuDice |
| ② | 单一处理者 | 同一输出只能有一个"抓取→替换→渲染"管线 | 骰子结果渲染 → B 唯一接管 |
| ③ | 成熟度倒挂 | 复杂逻辑归"重工程"方，DND 美术归"专精"方 | 校验/表格/预设→B；主题/HUD/地图→A |
| ④ | 数据源唯一 | 地图地点、模板体系"双源即故障" | 地点表、模板 → 各定一个源 |
| ⑤ | 入口就近 | 入口跟着玩家视线，机制沉在底层 | DND 按钮长在 A 界面、机制用 B |

### 6.3 重点域代码级详解

**① 行动/选项按钮 —— 两条机制对比**

| | A（仪表盘） | B（骰子系统） |
|---|---|---|
| 数据源 | 写死 `UI_ActionOptions` 表 | 任意表（`table_keywords` 匹配） |
| 灵活度 | 固定「选项A-D」4 列 | 自定义→内置→预设 三层规则 |
| 点击行为 | 发送文本到 `#send_textarea` | `template` 模板变量（`<user>前往{Name}。`）+ `auto_send` |
| 管理 | 无 | `ActionPresetManager` + 图标映射 + `__none__` 全禁用 |

结论：B 机制是 A 的超集（给 `UI_ActionOptions` 配一条规则即可复刻 A 行为）；A 按钮留在 HUD（入口就近）。共存默认不冲突（关键词域不同），注意别给同一表配双规则。

**② 检定引擎 —— 软约束 vs 硬保证**

- A：`DiceRulesInjector` 把 5E 规则**注入提示词**，让 AI 自算（软约束，AI 会算错）；
- B：`build-check-value-text` 本地引擎算（`属性值12（调整值+2）+技能加值+3`），normal/contest 双模式（硬保证）。

两种防作弊哲学：
- A"预防型"：预生成 d20 池 → 写进提示词，AI 只能抽用、没法编；
- B"治理型"：真随机引擎 + 界面隐藏 + 覆盖/回溯。

融合姿势：**B 引擎做计算（默认）；A 骰子池降级为"提示词层兜底"（可选）**——与移植清单 b9 策略一致。

**③ 骰子结果处理 —— 正则冲突实锤**

B 教程原文警告："隐藏聊天记录中的检定结果**有可能与酒馆全局的正则冲突**"。而 A 的 `dist/正则/骰子正则.js` 正是一个全局正则（249 行卡片样式）。
结论：抓取/隐藏/替换权归 B（占位符/覆盖/隐藏三开关）；A 卡面仅做皮肤。共存时只留一个接管者。

**④ 表格编辑器 —— 为什么留 B**

- B：`features/table/` 上百模块——CRUD、写前锁预检、单元格菜单、批量、审计 + `database-ui-override`；
- A：`UITableManager`（44KB）——界面工具，无锁。

双编辑器写同表 = 写冲突。融合后 B 唯一编辑，A 降为只读/跳转。

**⑤ 必须统一的数据源（地图/模板）**

B `map-visualization` 与 A `UIMap` 都读"当前地点"。双源 = 仪表盘显示 A 地、骰子系统显示 B 地、AI 上下文混乱。
统一【2026-10-04 数据层对账】：**叙事层唯一源 = 基座「世界地图点」+「地图元素表」**（含 location_id/element_id），「当前地点」= 全局数据表三级字段；DND「探索地图数据」（渲染整图 JSON，freq=0）未入基座——**表级处置待拍板**（建议：补表为第 21 表，渲染/叙事分工）。战斗地图 2 表（zhandouditu / huizhi）已并入基座 ✅。模板唯一源 = `DND5E_SQL_9.20`（DND 场景）。

**⑥ 顺手合并三件**

- **骰子历史统计**：B `dice-panel-history` 体系完整，A 无——数据归 B，展示可放 A 面板；
- **数据校验引擎**：B `validation-engine` + `smart-fix` + 规则管理，A 空白而 AI 填表场景最需要——净收益合并；
- **教程系统**：B `TUTORIAL_SCOPE_LIST` 框架，A 无——统一挂 B。
