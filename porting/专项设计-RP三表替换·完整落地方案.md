## 三、S1 数据层 v4 · 扩列清单（可直接执行）

> 全部新增列均可空、旧数据零迁移；执行管线同 v2/v3（三处同步：表头 / ddl / note；契约+SQLite+备份）。

### 3.1 世界地图点（sheet_world_map）+4 列（**全部隐藏**）

| 列（表头名） | 类型 | 隐藏 | 用途 |
|---|---|---|---|
| `MapStructureJSON` | TEXT | ✅ | 探索结构（原探索地图数据.MapStructureJSON） |
| `LastUpdated` | TEXT | ✅ | 更新时间戳（原表同名） |
| `当前显示地图` | TEXT | ✅ | 覆盖锚（原表同名，DND 代码零改名） |
| `VisualJSON` | TEXT | ✅ | 战斗场景结构（原战斗地图绘制.VisualJSON，场景=详细地点） |

**声明位置**：`sheet_world_map.sourceData.hiddenPhysicalColumns = ["MapStructureJSON","LastUpdated","当前显示地图","VisualJSON"]`
（身份口径：按插件版本以**表头名**落地；实施时以 reconciler 行为校准。）

### 3.2 ⚔️战斗遭遇表（sheet_zhandouzaoyubiao）+4 列（**可见**）

| 列 | 类型 | 用途 |
|---|---|---|
| `坐标` | coord "x,y" | 单位战场位置（原战斗地图.坐标） |
| `大小` | size "w,h" | 单位占格（原.大小） |
| `Token` | TEXT | Token 图标/样式（原.Token） |
| `网格` | TEXT | 本场网格尺寸 "20x20"（原 Config 行） |

> 与「先攻/位置」列职责分离：先攻值/文本位置保留原义；新增列为战场技术属性。可见（轻量，允许 AI 维护移动——与现状战斗地图表可写性一致）。

### 3.3 地图元素表（sheet_map_elements）+2 列（可选·建议本期）

| 列 | 类型 | 用途 |
|---|---|---|
| `坐标` | coord | 元素点位（图层化/点击交互前置门） |
| `图标` | TEXT | 自定义图标（缺省走 emoji 自动分配） |

### 3.4 全局数据表（sheet_global_data）+2 列（顺带）

| 列 | 用途 |
|---|---|
| `战斗模式` | 模式开关（原全局状态.战斗模式；"本轮故事模式"≈锚点候选，二选一实施时定） |
| `场景描述` | 战斗/地图生成参数（原全局状态.场景描述） |

## 四、S2 代码适配映射（函数级·6-8 处）

| # | 位置（DND 源码） | 现状读取 | 改为 |
|---|---|---|---|
| 1 | `ExplorationMapManager.checkStructure` | `EXPLORATION_Map_Data` → MapStructureJSON | `世界地图点` → `MapStructureJSON` |
| 2 | `saveStructure` | 写探索表 | 写世界地图点（隐藏列，系统写） |
| 3 | `getMap` override 段 | 探索表.当前显示地图 | 世界地图点.`当前显示地图` |
| 4 | `checkBattleStructure/saveBattleStructure` | `COMBAT_Map_Visuals` → VisualJSON | 世界地图点.`VisualJSON` |
| 5 | `UIMap.renderMiniMap` 探索段 | 同 #3 | 同 #3 |

| 7 | 全局读取 | `当前场景/场景描述/战斗模式` | 全局表.`当前详细地点` 映射 + 新列 |

## 五、S3 验收清单（酒馆实测）

1. **探索**：选地点 → 生成结构 → 写回世界点（隐藏列）→ 刷新/重开 → 读回一致；「当前显示」覆盖生效；
2. **战斗**：开战 → 网格/Token 从遭遇表读 → 单位移动后重绘正常；Token 头像正常；
3. **污染检验**：连续多轮对话后，渲染 4 列内容**未被 AI 触碰**（对比快照）；
4. **导出**：模板导出包含隐藏列（结构不丢）；
5. **回归**：b1/b2 既有验收钩子（读设置/读表）不受影响。
