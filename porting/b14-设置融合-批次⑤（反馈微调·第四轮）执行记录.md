## 一、问题与根因（三类）

1. **③④ 同一根因——「接线缺口」（导出遗漏）**：
   - `index.ts` 从 `check-suggestion-wiring` 解构 10 个函数，但该 wiring 的**对外返回只列了 8 个**——漏了 `showTemplateInspectionModal` 与 `showTableTemplateRequirementPresetManager`（二者内部已创建）；
   - 结果：DND 主面板「检验表格模板」「模板检验预设管理」两个入口调用到 `undefined` → 被各级 catch 静默 →「点击无反应」（此前两轮层级修复方向不对，根因在接线）；
   - 探针实测证据：`showTemplateInspectionModal()` 抛 `zc is not a function`；`openDicePresetManager('templateRequirement')` 抛 `Bc is not a function`。
2. **③ 第二层根因——「幽灵导入」（随第一层修复而暴露）**：
   - `wiring/advanced-preset-wiring.ts` 从 `table-template-requirements` 导入了**不存在**的名字 `getRequirementInspectionSheets`（该模块只有 `getTemplateInspectionSheets`；`index.ts` 是带别名导入的）→ undefined；
   - 该名字被 `getTableTemplateRequirementPresetStats()`（渲染「模板检验预设管理」弹窗列表的第一步）调用 → TypeError；
   - **遗留了多个版本的构建警告**（"export 'getRequirementInspectionSheets' ... was not found"），此次一并清除（构建 warnings 从 4 → 3，仅剩体积类）。
3. **⑤——「中转打开」体验问题**：
   - 「数据验证预设 / 表格正则预设」的管理入口历史实现为「打开骰子设置弹窗 → 再自动进入其内嵌二级管理弹窗」，用户可见「先弹出设置弹窗」。

## 二、修复内容

1. **接线修复**：① wiring 返回补全 2 个成员；② 桥补 `showTableTemplateRequirementPresetManager` 成员（`showTemplateInspectionModal` 桥内已有、补值即通）。
2. **幽灵导入修复**：`getTemplateInspectionSheets as getRequirementInspectionSheets`（与 index.ts 同款别名）。
3. **⑤ 静默直达**：`showSettingsModal({ openManager, silentManager: true })` —— 打开设置弹窗外壳的同时**立即隐藏设置主窗**（新增 `acu-manager-silent` 样式：`.acu-edit-dialog.acu-settings-dialog{display:none}`），仅显示目标二级管理弹窗；关闭二级（按钮 / 遮罩 / Esc）时**整体销毁**。仅作用于 validation / regex 两项，其余不变。
4. **提示加固**：相关按钮失败提示升级为 `window.toastr || window.parent.toastr`（iframe 兜底）；「预设管理」入口 / `openDicePresetManager` 失败路径加可见提示（失败不再静默）。
