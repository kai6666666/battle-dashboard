# b14.18 热修记录 —— GID 菜单：解析实体色内联 + 命中诊断

> 来源：用户复测（b14.17 仍不可见）+ 对比骰子系统要求
> 版本：**v0.0.98-b14.18**

## 一、对比结论（骰子 vs Mini HUD）

| 环节 | 骰子面板 | Mini HUD | 差异 |
|---|---|---|---|
| 触发链 | 同一 bind 代码 | 同一 | 无 |
| host 宿主 | body 下 | body 下 | 无 |
| z-index | 2147483600/601 | 同 | 无（b14.16 已提升） |
| 定位 | 屏内 | 屏内 (rect 取证) | 无 |
| **颜色来源** | root=`#acu-dice-root` 带 acu-theme-* | **root=回退容器，主题类/变量可能不全** | **差异点** |
| **CSS 注入** | 骰子根作用域样式齐全 | **floating-host 规则在 MVU_STYLES，主文档未必注入** | **差异点** |

## 二、本次热修

- 视觉兜底 v2：在菜单浮出时**解析出实体颜色**（getComputedStyle 读变量，读不到用默认值）后**直接内联**，不再依赖 var 级联或外部 CSS 注入；
- 新增 **elementFromPoint 命中诊断**：输出菜单中心点最顶层元素（判断是否被遮挡）。

## 三、质量闸门

- tests 16/16；十五套冒烟全过；guardrails 通过；TS 0 诊断；bundle 3,831,068 B。

## 四、复测指引

- 点击对象按钮 → 菜单应可见（深色底 + 边框 + 文字）；
- 若仍不可见：把 `[GID]命中诊断` 日志行发我（top=... isMenu=...）。
