## 一、① 交互总览「按钮菜单」点击无反应 —— 根因与修复

### 根因（实测复现锁定）
- `toggleGlobalInteractionRow` 的 debug 代码调用 `getBoundingClientRect().toJSON()`；
- **部分 WebView / DOMRect 实现没有 `toJSON` 方法** → 抛 `toJSON is not a function` → **整个点击 handler 崩溃** → `is-expanded` 未加 → 菜单不弹；
- 骰子面板（iframe 环境）实现不同故正常。

### 修复
1. **核心**：新增 `safeDomRectJson()` 安全序列化（含 toJSON 存在性检测 + 手写字段回退 + try/catch），替换两处 debug 调用点；
2. **容错**：`hydrateGlobalInteractionAvatars` 包 try/catch（防早段异常阻断全部绑定）；
3. **回退**：floating-host 无骰子根时回退 `.acu-embed-scope` 容器（主题类/变量继承）；
4. **诊断**：桥新增 `__dndGIDLastBind` / `__dndGIDLastClick` 状态记录（供复测导出）；
5. **加固**：Mini HUD 绑定增加 1200ms 二次重绑。

## 二、② 底部4弹窗头部对齐（背包/已装备/势力与声望/NPC列表）

- 标题行统一为骰子面板头部机制：`nowrap + 标题 flex:1 收缩 + 计数 nowrap + 关闭按钮入列右侧`；
